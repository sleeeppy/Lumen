## 소개

탄막을 가르며 보스를 쓰러뜨리는 게임을 좋아하나요?

팀 **ChoCollect**는 그 긴장을 밤의 도시 옥상에 옮겨, 짧은 보스 러시로 담아 봤어요.
로비에서 NPC와 대화를 나누고 장신구를 고른 뒤, 페이즈가 갈리는 보스전으로 들어갑니다.

대시와 비행이 한 흐름으로 이어집니다. 한 줄만 더 비집고 들어가면 될 것 같은데, 한순간 맞으면 다시 옥상.
그래도 보스가 쓰러지는 그 순간이 있어서, 다시 대시를 켜게 됩니다.

대시와 비행은 **에너지 게이지**를 씁니다. 땅에 서 있으면 다시 찹니다.
**타이틀 → 로비 → 보스전.** 쓰러지면 로비로 돌아갑니다.



## 주요 기능

- **대시와 비행** — 지상에서 짧게 무적이 되고, 이어서 공중을 누빕니다
- **페이즈 보스** — 체력이 바닥날 때마다 궤도탄, 유도탄, 낙하탄이 섞입니다
- **장신구 빌드** — 반지 2개 · 팔찌 1개 · 네일 1개로 체력, 공격, 스킬이 바뀝니다
- **옥상 로비** — NPC와 대화하고, 상점을 열고, 보스로 들어갑니다
- **탄막 돌파** — 대시로 한 줄을 가르고, 네일로 주변을 지웁니다
- **macOS / Windows** — 릴리스에서 빌드를 받아 바로 실행할 수 있습니다
